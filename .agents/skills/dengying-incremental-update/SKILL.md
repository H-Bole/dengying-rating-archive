## 找到上次边界

1. 记住本次打开动态页时的顶部普通动态，作为本轮固定上界。按页面顺序从新到旧审阅，展开被截断且影响判定的正文。只检查卡片作者本人内容；评论、他人转发原文和视频标题不能代替其明确评级。
2. 优先比对 `checkpoint.anchors` 中最新普通动态的 ID。页面没有直接链接时，点击卡片**作者头部的发布时间**，读取新开页的 `t.bilibili.com/<id>` 或 `bilibili.com/opus/<id>` 地址并核对作者、完整日期；去掉追踪参数。不能从转发嵌套卡片取错链接。`2026-10-27` 这样的采集日期只是检查日期，不能作为动态流的停止条件。
3. 遇到主锚点即停止向下采集。主锚点若缺失，可继续到最近的备用锚点；用状态中已审阅 ID 去重，只将确认属于上轮上界之后的未知卡片计作新增。不能仅凭一个较老日期或内容相似就宣布连续性成立。
4. 锚点全部缺失、加载中断、时间顺序异常或新旧归属无法确定时，保留旧检查点，报告已核查范围及缺口，请用户决定是否扩大回查；不得自动全历史扫描。缺少状态时同样先报告，不从最近评级日期猜边界。
5. 抓取期间新出现于固定上界之后的动态留给下一轮；提交检查点前轻量复看顶部。置顶移动、分页重复和同一动态重现均按字符串 ID 去重，ID 不转为 JavaScript Number。

只保留每张卡核验所需的一至两句短摘录。内容比对退路使用作者、完整发文时间、本人正文短摘录及转发对象 ID，排除点赞、评论计数和“几小时前”等变化文本；不能只用“片名|评级”作为动态身份。无法唯一确认时报告缺口。

## 记录与归纳

- `data/update-state.json` 保存 `checkpoint`、首次 `calibration` 和追加式 `batches`。每个批次记前后锚点、检查时间、逐卡结果和计数。每张新增卡保存字符串 ID、永久链接、发文时间及其精度、短摘录、include/exclude 和具体理由、关联电影；未能判定则保留为待复核并暂停推进检查点。
- 本地卡片索引永久保留。新卡索引取完整 `window.RATING_ARCHIVE.audit` 与已保存批次中的最大索引加一；首次新卡从 #463 起，不能只看校准的 #1—#4。绝不按动态页的新位置重排历史索引。置顶卡和重叠卡已记录的不重复加数。
- 对账：本轮新增唯一动态数 = 本轮收录卡数 + 本轮排除卡数；新电影数、旧电影新评级数、评级事件数另报。一张动态可涉及多部电影，不能拿事件数代替动态数。首次校准的 `newDynamicCount: null` 表示旧边界证据不足，不能报告为零或精确新增数。
- 仅收录本人明确电影名及明确评级。新电影先核对已有片名、别名和 TMDB ID；旧电影的新评级追加到历史，不覆盖原评级。保留原句、日期、暂定/调级状态；正式八档及上中下细分分开保存，特殊评级不并入八档排序。
- 转发自己的旧评价且有明确调级时，转发为新事件，引用原评级若已存在则不重复创建。来源保留各自动态 URL。能核验时保存精确发文时间；同日评级按发文先后选当前评级，不用新增本地索引或评级高低推断时间。
- 初始档案的 462 张审阅卡属于旧快照，除校准的顶部卡片外没有稳定 ID；勿捏造其来源。首次校准已将《生化危机爆发夜》的原评级定位到卡片 #4、调级定位到 #3，状态中保留修正记录。

## 更新离线网站

- `ratings.js` 当前为自包含 IIFE：`rows` 五列 `[cardIndex,date,title,rawRating,status]` → `events` → 按电影聚合 `movies`；`tmdbByTitle` 挂载资料，最后生成 `window.RATING_ARCHIVE`。修改前读当前实现，复用结构，不新增框架、构建工具或采集服务。
- 新增记录时将逐卡来源、精确时间及具体排除原因同步到离线数据；同步扩充 `audit` 和 `meta`，不能继续固定 462 或为未审阅卡自动生成排除理由。首页审阅数来自 `audit.length`，检查日期维持 `YYYY-MM-DD`，精确检查时间放状态文件。
- 当前旧实现先按日期、状态和反向索引聚合，再在末尾校准段补 `publishedAt`。遇到同日新事件时，必须先补精确时间再选当前评级，或补后重算 `currentRating`；只给末尾 `verifiedCards` 加记录无效。同步让页面修订记录排序采用已核验的发文时间，保留显示日期；同日先后证据不足时列待复核，不沿用反向索引猜测。
- `tmdb` 已有字段：`id,titleZh,originalTitle,releaseDate,overview,poster,director,cast,runtime,countries`。已有电影复用资料；只为新电影补齐并消歧。上映日优先中国内地正式公映日期，缺失时用已核验的其他地区/首映日期并注明口径，不拿评分日期充当上映日期。
- 海报保存在 `assets/posters/tmdb-<id>.jpg`，供离线使用。TMDB 密钥仅使用当前获准的安全来源；缺失时报告所需凭据或改用可核验的公开资料，不从聊天历史或浏览器设置中挖取密钥，不把密钥写入技能、源码、状态或 Git。
- 保留 TMDB 归属说明。未能确认的片名、评级或资料列为待复核，不猜补；没有处理完的新动态不能被新检查点跳过。
